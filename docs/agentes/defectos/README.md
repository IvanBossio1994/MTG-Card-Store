# Defectos reportados por QA

Cada defecto es un archivo `DEF-XXX-<tema>.md` (formato en `../qa-guia.md`). QA agrega una fila acá al reportarlo, y el líder actualiza el estado al corregirlo o descartarlo.

**Estados:**
- **abierto:** recién reportado.
- **en corrección:** asignado a una historia de arreglo.
- **corregido:** el desarrollador lo arregló y falta que QA lo vuelva a probar.
- **cerrado:** QA confirmó que quedó bien.
- **descartado:** no es un defecto, con el motivo.
